# 🌿 Swachh Sathi - Smart Civic Waste Ecosystem (Alandi)

A comprehensive civic tech web platform designed for the historic temple town of Alandi (Devachi Alandi, Maharashtra) to streamline waste reporting, live GPS tracking, AI-powered segregation, and community cleanliness drives.

---

## 🌟 Key Features

1. **Live GPS Waste Hotspot Map**: Real-time Leaflet map showing reported waste heaps across Alandi's 6 municipal wards with status badges (Pending, In Progress, Resolved).
2. **AI Waste Segregation Assistant**: Classifies items instantly into Wet, Dry, Plastic, or Hazardous categories with disposal guidance.
3. **Multilingual Architecture**: Instant toggling between English (EN), Marathi (मराठी), and Hindi (हिंदी).
4. **Authentic Ward Sanitation Heroes Directory**: Direct phone call and WhatsApp dispatch to local municipal ward supervisors.
5. **Dual-Role Portal (Citizen & Admin)**:
   - **Citizen Dashboard**: Report issues, track complaints, schedule doorstep garbage pickups, and earn civic points.
   - **Municipal Admin Panel**: Real-time KPI counters, dispatch supervisors, mark hotspots resolved, and export CSV reports.

## 🚀 Quick Start (Local)

### 1. Run with 1-Click:
Double-click `launch.bat` in the project root.

### 2. Manual Start:
```bash
npm install
npm start
```
Open [http://localhost:5000](http://localhost:5000) in your browser.
